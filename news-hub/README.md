## Deskripsi, fitur/menu

1. Landing page
   - Berita berdasarkan kategori
2. Login page
   - Login untuk admin
   - Login untuk user
3. Register page
   - Register untuk user
   - Register untuk admin
4. Admin page
   - Menambahkan berita
   - Menghapus berita
   - Mengedit berita
